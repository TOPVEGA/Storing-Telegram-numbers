## 📌 نبذة عن المشروع

**Storing Telegram Numbers** مشروع بوت تيليجرام مكتوب بلغة Python، يضم واجهة للمستخدمين ولوحة إدارة، مع وظائف لإدارة سجلات الأرقام، والمحفظة، والإحصائيات، والمعاملات، والإحالات، والمكافآت.

يعرض هذا الملف المكونات والوظائف الموجودة في ملفات المشروع. لا يعني توثيق أي وظيفة أن استخدامها قانوني أو آمن في جميع الحالات؛ يجب الالتزام بشروط Telegram والقوانين المحلية والحصول على موافقة صريحة من مالكي الحسابات والبيانات.

## ✨ المميزات

### 👤 واجهة المستخدم
- قائمة رئيسية للوصول إلى أقسام البوت.
- عرض المحفظة والرصيد.
- عرض إحصائيات المستخدم.
- سجل المعاملات.
- البحث وطلبات مخصصة.
- نظام إحالة ومكافأة يومية.
- قسم للدعم والتواصل.
- عرض قنوات الاشتراك.

### 💳 المحفظة والمعاملات
- تسجيل حركات الرصيد والمعاملات.
- إحصائيات مرتبطة بنشاط المستخدم.
- دعم عمليات الإيداع وإدارة الرصيد بحسب منطق المشروع.
- إنشاء معرفات للمعاملات.

### 📊 لوحة الإدارة
- عرض إحصائيات البوت والتقارير.
- الاطلاع على بيانات المستخدمين.
- إدارة صلاحيات المشرفين.
- إدارة الحظر وإلغاء الحظر.
- إدارة قنوات الاشتراك.
- إرسال رسائل جماعية.
- إدارة الأرصدة ومراجعة المعاملات.
- تقارير يومية وعامة وإحصائيات الدول والبائعين.

### 🗄️ إدارة البيانات
- قاعدة بيانات PostgreSQL عبر `asyncpg`.
- استخدام Redis للتخزين المؤقت عند تهيئته.
- وظائف لتسجيل الأحداث والمعاملات.
- وجود وظائف تشفير وفك تشفير في طبقة قاعدة البيانات.

### 🌐 واجهة الويب
يتضمن المشروع تطبيق Flask مع مسارات للوحة المعلومات وفحص الحالة وبعض الإحصائيات، مثل عدد المستخدمين وأفضل البائعين والدول.

## ⚙️ الإعدادات

تُقرأ إعدادات المشروع من متغيرات البيئة، وتشمل — بحسب `config.py` — بيانات اتصال Telegram، ومعرف المالك، واتصال قاعدة البيانات، ومفتاح التشفير، وإعدادات Redis وواجهة الويب وقنوات الاشتراك.

**تنبيه أمني مهم قبل أي تشغيل أو نشر:**
- لا تضع `BOT_TOKEN` أو `API_HASH` أو كلمات المرور أو مفاتيح التشفير داخل مستودع عام.
- راجع `config.py`؛ يحتوي الملف الحالي على قيم افتراضية حساسة وإعدادات كلمة مرور موحدة. يجب إزالة القيم الافتراضية غير الآمنة وتوليد أسرار مستقلة وقوية، وعدم استخدام كلمة مرور موحدة للحسابات.
- لا ترفع ملفات الجلسات أو قواعد البيانات أو سجلات الدخول أو رموز التحقق إلى GitHub.
- لا تخزن أو تنقل رموز تسجيل الدخول أو كلمات مرور التحقق بخطوتين إلا ضمن تدفق موثوق ومصرح به، وبموافقة واضحة من صاحب الحساب.
- لا تستخدم المشروع للاستحواذ على حسابات الغير أو تداول الوصول إليها أو تجاوز حماية Telegram.
- قبل إتاحة أي لوحة ويب، راجع المصادقة والصلاحيات وحماية المسارات من الوصول غير المصرح به.

## 🔐 الخصوصية والاستخدام المسؤول

قد يتعامل المشروع مع أرقام هواتف وبيانات حسابات ومعاملات ومعلومات تحقق حساسة. لذلك يجب:
1. جمع الحد الأدنى الضروري من البيانات وبموافقة أصحابها.
2. توضيح الغرض من جمع البيانات ومدة الاحتفاظ بها.
3. تقييد الوصول إلى البيانات وفق صلاحيات واضحة.
4. حماية النسخ الاحتياطية وسجلات التشغيل ومفاتيح التشفير.
5. توفير آلية لحذف البيانات عند انتفاء الحاجة إليها أو بناءً على طلب صاحبها، حيثما يلزم.
6. مراجعة شروط Telegram والقوانين المعمول بها قبل استخدام أي وظيفة تتصل بالحسابات.
